# Font attribution

Both families are self-hosted under `public/fonts/`. No external font
requests are made at runtime.

## Geist (display / sans role)

- Source: [`geist@1.7.2`](https://www.npmjs.com/package/geist) (npm), `dist/fonts/geist-sans/`
- Publisher: Vercel, in collaboration with basement.studio
- License: SIL Open Font License 1.1 — `geist-OFL.txt`
- Weights vendored: Regular (400), Medium (500), SemiBold (600), Bold (700)

## JetBrains Mono (technical mono role)

- Source: [`JetBrains/JetBrainsMono`](https://github.com/JetBrains/JetBrainsMono) release [`v2.304`](https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304) (commit `cd5227b`), `fonts/webfonts/`
- Publisher: The JetBrains Mono Project Authors
- License: SIL Open Font License 1.1 — `jetbrains-mono-OFL.txt`
- Weights vendored: Regular (400), Medium (500)

Both licenses permit self-hosting, bundling, and modification (including
subsetting) without royalty, provided the font name is not sold on its own
and the license text accompanies redistribution — satisfied by this file.
