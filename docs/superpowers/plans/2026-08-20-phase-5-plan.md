> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the portfolio ecosystem by building the global Full-Screen Index, the secondary routes (About, Contact, Archive, Writing), and the Lab experimental engine. Ensure all features maintain the cyberpunk/retro-technical dossier aesthetic and pass all quality/performance gates.

**Architecture:** We introduce the `SiteIndex.astro` overlay connected to a navigation controller. The utility routes rely on static Astro generation powered by typed MDX/JSON data. The Lab environment extends the Phase 3 WebGL renderer to run seeded, audio-reactive, and data-driven experiments securely without compromising the main UI loop.

**Tech Stack:** Astro, TypeScript, DOM/CSS animations, Playwright

## Global Constraints

- Preserve and redesign every current public route.
- Implement a Four-Corner UI Framework and Vertical Sidebar Navigation.
- Maintain the Cyberpunk / Retro-Technical Dossier aesthetic.
- Do not copy reference source code, shaders, copy, fonts, images, video, 3D assets, or audio.
- Use only free and open-source runtime dependencies. Pin versions exactly in `package.json`.

// src/components/shell/SiteIndex.astro
---
<div id="site-index" aria-hidden="true" inert>
  <nav class="index-nav">
    <a href="/">HOME</a>
    <a href="/projects">WORK</a>
    <a href="/about">ABOUT</a>
    <a href="/lab">LAB</a>
    <button id="index-close">CLOSE</button>
  </nav>
</div>

<button id="index-trigger" class="corner-frame-top-right">INDEX</button>

<style>
  #site-index {
    position: fixed;
    inset: 0;
    background: rgba(5, 5, 5, 0.95);
    z-index: 200;
    opacity: 0;
    pointer-events: none;
    transition: opacity 0.3s ease;
    display: flex;
    align-items: center;
    justify-content: center;
  }
  
  #site-index[aria-hidden="false"] {
    opacity: 1;
    pointer-events: auto;
  }
  
  .index-nav {
    display: flex;
    flex-direction: column;
    gap: 1.5rem;
    font-size: 3rem;
  }
</style>

<script>
  const trigger = document.getElementById('index-trigger');
  const close = document.getElementById('index-close');
  const index = document.getElementById('site-index');

  if (trigger && close && index) {
    trigger.addEventListener('click', () => {
      index.setAttribute('aria-hidden', 'false');
      index.removeAttribute('inert');
      document.body.style.overflow = 'hidden';
    });

    close.addEventListener('click', () => {
      index.setAttribute('aria-hidden', 'true');
      index.setAttribute('inert', '');
      document.body.style.overflow = '';
    });
  }
</script>
```

// src/runtime/rendering/scenes/lab/ExperimentRegistry.ts
export class ExperimentRegistry {
  private experiments: Map<string, any> = new Map();

  public register(id: string, experimentClass: any) {
    this.experiments.set(id, experimentClass);
  }

  public get(id: string) {
    return this.experiments.get(id);
  }
}
```
